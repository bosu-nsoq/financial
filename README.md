# 💰 Financial & Expense Tracker (ระบบบันทึกรายรับ-รายจ่ายและการเงิน)

เว็บแอปพลิเคชันบันทึกรายรับ-รายจ่ายและการเงิน พัฒนาด้วย **Google Apps Script (GAS)** เชื่อมต่อฐานข้อมูล **Google Sheets** แบบเรียลไทม์ พร้อมหน้าตาเว็บแบบ **Glassmorphism**, ฟอนต์ **Mali**, รองรับวันที่ไทย **พ.ศ. (dd/mm/yyyy)** และรองรับ **PWA (Progressive Web App)** ติดตั้งใช้งานบน iOS/Android ได้เต็มจอ

---

## ✨ ฟีเจอร์เด่นของระบบ

1. **บันทึกรายรับและรายจ่าย (ฝาก/ถอน):**
   - รองรับการเลือกวันที่ย้อนหลังหรือล่วงหน้าได้ พร้อมแปลงเป็นปี **พ.ศ. (dd/mm/yyyy)** อัตโนมัติ
   - ช่องเลือกวันที่คลิกแล้วเปิดปฏิทินทันที ไม่มีไอคอนเกะกะ
   - เลือกหมวดหมู่และรายชื่อสมาชิก/นักเรียนแบบ Dynamic Dropdown
2. **Dashboard สรุปยอดเงินภาพรวม:**
   - รายรับรวม (ฝาก)
   - รายจ่ายรวม (ถอน)
   - ยอดคงเหลือสุทธิ (คำนวณเรียลไทม์)
3. **ระบบจัดการฐานข้อมูลในตัว:**
   - เพิ่มหมวดหมู่ใหม่ได้ทันทีจากหน้าเว็บ
   - เพิ่มรายชื่อสมาชิก/นักเรียนตามหมวดหมู่
4. **ตรวจสอบยอดและประวัติ:**
   - Modal เช็คยอดคงเหลือรายคน
   - Modal ดูประวัติรายการย้อนหลังรายบุคคล
   - Modal แสดง 10 รายการล่าสุด พร้อมปุ่มลบรายการที่คำนวณยอดใหม่ให้อัตโนมัติ
5. **ดีไซน์และ PWA:**
   - พื้นหลังเคลื่อนไหวแบบ Gradient สีพาสเทล พร้อมการ์ดกระจกฝ้า Glassmorphism
   - ตัวอักษรฟอนต์ **Mali** สวยงาม อ่านง่าย
   - รองรับ **PWA** เพิ่มลงหน้าจอโฮม (Add to Home Screen) เป็น Standalone App บน iPhone / iPad และ Android

## 📁 โครงสร้างโปรเจกต์

```text
financial-tracker/
├── Code.gs             # โค้ด Backend Google Apps Script (ประมวลผลข้อมูลและซิงค์ Sheets)
├── Index.html          # หน้าเว็บ Frontend (HTML, CSS, JS, Glassmorphism, PWA)

├── sw.js               # Service Worker สำหรับ PWA
├── appsscript.json     # ไฟล์ตั้งค่า Apps Script Runtime
└── README.md           # คู่มือการติดตั้งและใช้งาน
```

## 🚀 วิธีการติดตั้งบน Google Apps Script

1. เปิด [Google Sheets](https://sheets.new) เปล่าขึ้นมา 1 ไฟล์
2. ไปที่เมนู **ส่วนขยาย (Extensions)** > **Apps Script**
3. ลบโค้ดเดิมใน `Code.gs` แล้วนำโค้ดจากไฟล์ [`Code.gs`](./Code.gs) ไปวางแทนที่
4. กดเครื่องหมาย `+` ด้านซ้ายมือ เลือก **HTML** แล้วตั้งชื่อว่า `Index`
5. นำโค้ดจากไฟล์ [`Index.html`](./Index.html) ไปวางแทนที่
6. กดปุ่ม **บันทึกโครงการ (รูปแผ่นดิสก์)**
7. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** > **การทำให้ใช้งานได้รายการใหม่ (New deployment)**:
   - เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: `Financial Tracker v1`
   - ปฏิบัติการในฐานะ: **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
8. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป** ไปใช้งานได้ทันที!
